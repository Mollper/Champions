# UniRoute

AI-сервис для абитуриентов 9–11 классов: короткая анкета → диагностика профиля → подбор вузов → сравнение → персональный roadmap поступления.

**Стек:** Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · Framer Motion · lucide-react · Supabase (Postgres, Auth, RLS) · Vercel.

## Что внутри

| Путь | Что делает |
| --- | --- |
| `/` | Анимированный лендинг (Framer Motion), реальные вузы из БД |
| `/login` | Вход и регистрация (Supabase Auth, email + пароль) |
| `/profile` | Анкета из 7 шагов с живым подбором, прогресс сохраняется на каждом шаге |
| `/overview` | Диагностика: цель, готовность, сильные стороны и ограничения |
| `/recommendations` | Вузы с фото, шансом, объяснением «почему подходит», стоимостью с учётом стипендий |
| `/compare` | Сравнение 2–4 вузов по приоритетам пользователя |
| `/roadmap` | План по месяцам + календарь дедлайнов, отметка прогресса |
| `/dashboard` | Главная: один выделенный «следующий шаг» |
| `/scholarships` | Подбор стипендий с проверкой условий |
| `/api/assistant` | ИИ-помощник (стрим ответа, история, 4 стиля общения) |
| `/api/recommendations` | Подбор в JSON |
| `/api/catalog/requests` | «Не нашли свой вуз?» — заявка, которую ИИ-каталог обрабатывает в фоне |
| `/api/cron/catalog` | Ежедневно: необработанные заявки и обновление устаревших ИИ-записей (Vercel Cron, `CRON_SECRET`) |

**Движок** (`src/lib/engine`) — чистые функции: нормализация GPA и экзаменов, совпадение, шанс поступления с объяснением факторов, диагностика, генерация маршрута. Любое изменение анкеты повышает `profiles.version` (триггер учитывает только значимые поля) — рекомендации пересчитываются, маршрут перестраивается, выполненные шаги сохраняются.

**Анкета** принимает только реальные баллы (`src/lib/exams.ts`, проверка и в браузере, и на сервере): IELTS — от 0 до 9 с шагом 0.5, SAT — от 400 до 1600 с шагом 10, Duolingo — с шагом 5, остальные экзамены — целые числа. На невозможный балл (SAT 1465) поле подсказывает ближайшие допустимые.

**ИИ-помощник** (`src/lib/assistant`) пишет ответ бесплатной моделью: Groq `gpt-oss-120b` → Groq `gpt-oss-20b` → Gemini Flash Lite (следующая модель берётся при исчерпании лимита). Модель получает профиль, диагностику, подборку, маршрут, стипендии, вузы из вопроса и точный расчёт приложения для сценариев «а если бюджет $30k / IELTS 7 / хочу в Японию» (`rule-based.ts`) — цифры не придумывает. Если ни одна модель недоступна, отвечает тот же rule-based движок, контракт API не меняется.

**ИИ-каталог** (`src/lib/catalog`) дополняет 15 вручную проверенных вузов вузами «Предложено ИИ»: факты из Wikidata → страницы официального сайта и Википедии → Gemini извлекает стоимость, требования, дедлайны и направления с цитатой-источником для каждой цифры (или помечает её как оценку ИИ) → фото из Wikimedia Commons выбирает vision-модель. Записи без стоимости, направлений или фото остаются черновиками и в подбор не попадают. Источник каждой цифры виден на карточке («Шансы и источники»).

```bash
npm run catalog -- seed                        # список scripts/catalog-seed.ts (~115 вузов, 30 стран)
npm run catalog -- add "ETH Zurich" --country=CH
npm run catalog -- discover --countries=JP,CN --per-country=2
```

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать ключи Supabase, Gemini и Groq
npm run dev
```

## База данных

Миграции лежат в `supabase/migrations/`:

| Файл | Что делает |
| --- | --- |
| `…_init_schema.sql` | Таблицы `users`, `profiles`, `universities`, `scholarships`, `roadmaps`, `roadmap_steps`, `shortlist`, `chat_messages`; триггеры; явные GRANT; RLS-политики |
| `…_seed_universities.sql` | 15 реальных вузов (фото из Wikimedia Commons, ссылки на официальные сайты) и 16 реальных стипендий |
| `…_index_roadmap_steps_owner_fk.sql` | Покрывающий индекс для составного FK (по рекомендации `supabase db advisors`) |
| `…_profile_version_on_meaningful_change.sql` | Версия анкеты растёт только от значимых полей (не от стиля помощника) |
| `…_catalog_pipeline.sql` | ИИ-каталог: `origin`, `status` (черновики скрыты RLS), `wikidata_id`, источники по полям; таблица заявок `catalog_requests` |

Проект Supabase: **UFOCUSE** (`tdntqwsfqpjkxzkhpqqh`, регион ap-northeast-2). Новая миграция:

```bash
npx supabase migration new <name>
npx supabase db push --linked
npx supabase db advisors --linked
npx supabase gen types typescript --linked --schema public > src/types/database.ts
```

`src/types/database.ts` генерируется автоматически; строгие доменные типы (union-ы из CHECK-ограничений, форма jsonb) — в `src/types/models.ts`.

### Модель доступа

- `universities`, `scholarships` — справочники, чтение для всех (`anon`, `authenticated`), запись только `service_role`.
- Всё остальное — только владелец строки (`auth.uid() = user_id`). `users.email` менять нельзя (гранты по колонкам).
- `roadmap_steps` ссылается на `roadmaps (id, user_id)` составным FK — шаг нельзя привязать к чужому плану.
- `profiles.version` растёт при каждом изменении анкеты — по нему рекомендации и roadmap понимают, что устарели. Прогресс шагов сохраняется при перегенерации благодаря стабильному `step_key`.

### Демо-данные

Вузы, стипендии, ссылки и фотографии реальные, но цифры (стоимость, проходные баллы, доля поступивших, дедлайны) — **ориентировочные** на цикл 2026/27. У каждой записи есть `is_demo = true` и `data_source`; в интерфейсе они помечаются как «демонстрационные данные». Вузы из ИИ-каталога отмечены «Предложено ИИ», а у каждой их цифры указан источник: страница сайта с цитатой или «оценка ИИ — проверьте на сайте».
